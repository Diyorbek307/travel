# UzUp

Мобильное приложение-гид по Узбекистану: города, достопримечательности,
маршруты, отели, рестораны, транспорт и аудиогиды.

## Запуск

```
npm install
npm run dev
```

Откроется на http://localhost:3000.

## Как устроено

Приложение одностраничное: экраны переключаются состоянием внутри
макета телефона, как в дизайне, а не маршрутами Next.js.

```
src/
  app/          оболочка, глобальные стили
  components/
    screens/    вкладки: главная, исследовать, карта, аудио, профиль
    details.tsx карточки места, отеля, ресторана, маршрута
    modals.tsx  поиск, уведомления, вход, подписка
    widgets.tsx плеер, офлайн-пакеты, рекламный блок, всплывающие сообщения
  data/         содержимое приложения
  lib/          типы и палитра
```

Контент лежит в `src/data/content.ts` одним типизированным файлом.
Когда появится админ-панель, эти массивы заменит выборка из базы —
типы в `src/lib/types.ts` останутся прежними.
