# Сюда кладите свою базу

Папка для городов и достопримечательностей, которые вы собрали.
Положите файлы сюда и скажите «база в папке». Дальше я сам их проверю,
приведу к формату приложения и загружу.

## Что можно класть

- Таблицы: Excel (`.xlsx`) или `.csv`. Удобнее всего один лист «Города» и один «Достопримечательности».
- `.json`, Word, текст — тоже подойдут.
- Фото складывайте в `фото/`, по папке на город: `фото/Самарканд/registan-1.jpg`.

## Какие поля пригодятся

**Город:** название, регион, короткое описание, координаты.

**Достопримечательность:** город, название, тип (мечеть, музей, парк…), описание,
координаты или ссылка из Google/Яндекс Карт, часы работы, цена входа, фото.

Если чего-то нет, оставьте пустым. Выдумывать недостающее я не буду.

## Важно про фото

У каждого фото напишите, откуда оно: своё, Wikimedia, Unsplash, сайт музея…
Фото из Google Карт, Яндекса, Booking и чужих сайтов без разрешения брать нельзя,
иначе будут претензии по авторским правам.

Содержимое папки (кроме этого файла) в Git не попадает: репозиторий открытый,
а база — ваша работа.
